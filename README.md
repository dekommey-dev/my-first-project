# Allocare — AI 자동 투자 · 포트폴리오 관리 대시보드 (프론트엔드 MVP)

설문 기반 투자 성향 진단 결과에 맞춰 AI가 자산을 배분·리밸런싱하는 SaaS의 대시보드 화면입니다.
백엔드 연동 전 단계로, 결정적(seeded) 목업 데이터로 구동됩니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 체크 + 프로덕션 빌드
npm test           # 단위 테스트 (vitest)
```

## 화면 구성

토스 스타일의 절제된 UI(옅은 회색 바탕 · 테두리 없는 흰 카드 · 큰 숫자 · 해요체 문구)로 구성했습니다.
데스크톱은 메인/사이드 2단, 모바일은 요약 → 상세 순의 1단입니다.

| 영역 | 내용 |
|---|---|
| 총 자산 | 평가금액, 누적 손익·수익률, 투자 성향 배지, 입금/출금 버튼 |
| AI 리밸런싱 예정 | 다음 리밸런싱 날짜와 사유, 자산별 매수·매도 예정 금액 |
| 수익률 | 기간 수익률과 벤치마크 비교 문장, 누적 수익률 차트(리밸런싱 시점 표시·툴팁), 기간 탭(1개월~전체), 평가손익·최대 낙폭·리밸런싱 횟수 |
| 자산 비중 | 도넛 차트(호버/키보드 포커스 시 중앙 수치 전환), 자산군별 현재·목표 비중과 이탈(%p), 조정 안내 |
| 내 투자 성향 | 5단계 성향 미터, 설문 점수·진단일, 주요 응답, 기대 수익률, 적용 포트폴리오, 재진단 버튼 |
| 리밸런싱 내역 | 유형별 아이콘 리스트(정기·비중 이탈·시장 급변·성향 변경·최초 구성), 펼치면 AI 판단 근거와 자산별 매매 내역 |

## 구조

```
src/
  App.tsx                 대시보드 레이아웃 · 기간 상태
  components/             카드 단위 UI (HeroCard, InsightCard, ReturnsChart, AllocationDonut, RiskProfileCard, RebalanceTimeline …)
  data/mock.ts            목업 데이터 (API 응답 형태에 맞춘 타입 사용)
  lib/metrics.ts          기간 절단·재기준화, MDD, 비중 이탈, 매매안, 축 눈금 계산
  lib/format.ts           원화·퍼센트·날짜 포맷 (억/만 단위 축약 포함)
  types.ts                도메인 타입
  styles.css              디자인 토큰 (라이트/다크) 및 컴포넌트 스타일
```

## 설계 메모

- **색상 관례**: 국내 증권 관례에 따라 상승·매수는 빨강, 하락·매도는 파랑이며, 항상 부호(+/-)와 화살표 아이콘을 함께 표시해 색에만 의존하지 않습니다.
- **차트 팔레트**: 자산군 색상은 색각 이상(CVD) 분리도를 검증한 범주형 팔레트를 고정 순서로 사용하고, 다크 모드는 별도로 검증한 값으로 전환됩니다.
- **접근성**: 수익률 차트는 스크린리더용 데이터 표를, 도넛은 수치가 적힌 목록을 함께 제공하며 목록은 키보드로 탐색할 수 있습니다. 테마는 OS 설정을 따르며 상단 버튼으로 전환됩니다.
- **폰트**: Pretendard(가변, 동적 서브셋)를 번들에 포함합니다.
- **데이터 일관성**: 자산 평가금액은 누적 수익률 시계열에서 역산하고, 예정 리밸런싱 매매안은 현재·목표 비중 차이로 계산해 화면 간 수치가 서로 맞도록 했습니다.
- **API 연동 시**: `src/data/mock.ts`의 export를 fetch 결과로 대체하면 됩니다. 컴포넌트는 `types.ts`의 타입만 의존합니다.
