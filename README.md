# Allocare — AI 자동 투자 · 포트폴리오 관리 대시보드 (프론트엔드 MVP)

설문 기반 투자 성향 진단 결과에 맞춰 AI가 자산을 배분·리밸런싱하는 SaaS의 대시보드 화면입니다.
백엔드 연동 전 단계로, 결정적(seeded) 목업 데이터로 구동됩니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 체크 + 프로덕션 빌드
npm test           # 단위 테스트 (vitest)
```

## 화면 구성

| 영역 | 내용 |
|---|---|
| 조회 기간 필터 | 1개월·3개월·6개월·1년·전체 — KPI, 수익률 차트, 리밸런싱 내역에 한 번에 적용 |
| KPI 타일 | 총 평가금액(누적 손익), 기간 수익률, 벤치마크 대비 초과수익, 최대 낙폭(설문상 감내 한도와 비교) |
| 누적 수익률 추이 | 포트폴리오 vs 벤치마크 라인 차트, 기간 시작일 0% 재기준화, 크로스헤어 툴팁, 리밸런싱 실행 시점 마커, 표 보기 |
| 투자 성향 분석 | 5단계 성향 등급 미터, 설문 점수, 응답 요약, 기대 수익률·변동성, 적용 모델 포트폴리오, 재진단 |
| 자산군별 투자 비중 | 도넛 차트(호버/키보드 포커스 시 중앙 수치 전환) + 현재·목표 비중 및 이탈(%p) 막대, 표 보기 |
| 리밸런싱 내역 | 예정/완료 타임라인, 트리거 유형(정기·비중 이탈·시장 이벤트·성향 변경), AI 판단 근거, 자산별 매매 내역·거래비용 |

## 구조

```
src/
  App.tsx                 대시보드 레이아웃 · 기간 상태
  components/             카드 단위 UI (ReturnsChart, AllocationDonut, RiskProfileCard, RebalanceTimeline, KpiRow …)
  data/mock.ts            목업 데이터 (API 응답 형태에 맞춘 타입 사용)
  lib/metrics.ts          기간 절단·재기준화, MDD, 비중 이탈, 매매안, 축 눈금 계산
  lib/format.ts           원화·퍼센트·날짜 포맷 (억/만 단위 축약 포함)
  types.ts                도메인 타입
  styles.css              디자인 토큰 (라이트/다크) 및 컴포넌트 스타일
```

## 설계 메모

- **색상 관례**: 국내 증권 관례에 따라 상승·매수는 빨강, 하락·매도는 파랑이며, 항상 부호(+/-)와 화살표 아이콘을 함께 표시해 색에만 의존하지 않습니다.
- **차트 팔레트**: 자산군 색상은 색각 이상(CVD) 분리도를 검증한 범주형 팔레트를 고정 순서로 사용하고, 다크 모드는 별도로 검증한 값으로 전환됩니다.
- **접근성**: 모든 차트에 표 보기를 제공하고, 도넛 범례는 키보드 포커스로 탐색할 수 있습니다. 테마는 OS 설정을 따르며 상단 버튼으로 전환됩니다.
- **데이터 일관성**: 자산 평가금액은 누적 수익률 시계열에서 역산하고, 예정 리밸런싱 매매안은 현재·목표 비중 차이로 계산해 화면 간 수치가 서로 맞도록 했습니다.
- **API 연동 시**: `src/data/mock.ts`의 export를 fetch 결과로 대체하면 됩니다. 컴포넌트는 `types.ts`의 타입만 의존합니다.
